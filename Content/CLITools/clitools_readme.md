# Everything Search
es.exe is the command line tool for Everything Search
everything.exe is the gui and background service. 
everything-startup.vbs is a VB Script that will launch everything at startup. You can add this to %AppData%\Microsoft\Windows\Start Menu\Programs\Startup to make it run
<!-- You can set it to launch at startup in Tools > Options > General -->
