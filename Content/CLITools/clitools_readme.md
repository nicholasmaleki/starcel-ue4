# Everything Search
es.exe is the command line tool for Everything Search
everything.exe is the gui and background service. You can set it to launch at startup in Tools > Options > General
In order to stop the pop up asking for admin permissions every time you log in Right Click > Properties > Compatibility > Run this program as administrator
You can add the included shortcut to C:\ProgramData\Microsoft\Windows\Start Menu\Programs in order for it to show up in Start>Search, the one in the taskbar, faster
