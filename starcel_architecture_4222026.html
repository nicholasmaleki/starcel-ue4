03 /

Network topology · client ⇄ dedicated server

same main.py runs on both sides · branches on IsDedicatedServer()

Client

  • main.py · begin_play branch
  • spawns BP_PyDroneCharacter, possesses
  • wires HotkeyManager / mouse / traces
  • renders PyActors locally · math plots, tables, icons
  • send side of LargeStringAsyncStandalone
RPC · replication · multicast
Actor spawn → server · Multicast RPC → all clients
chunked · ticker-rate-limited
LargeStringRPCActor · 8 KB frames

Dedicated server

  • main.py · server branch (IsDedicatedServer=true)
  • binds OnPlayerJoined on StarcelGameMode
  • per join → spawn drone, Possess, create RPC_ACTOR
  • receive side of LargeStringAsync
  • advertises LAN + public IP (api.ipify.org)
04 /

Runtime lifecycle · what happens on play

call order, top to bottom

① Map loads

default level contains a PyActor configured to main.Main

② PyActor constructs · imports main.py

modules loaded: constants · languages · cli · nd_table · input_devices · ue_spawn · icon_to_image · test_spawn

③ Main.begin_play()

world cache → keyboard/mouse → HotkeyManager → TraceHelper → branch on server/client

④ Drone spawn & possession

world.actor_spawn(BP_PyDroneCharacter) → PlayerController.Possess() → py_proxy._setup_input()

⑤ Demo suite

test_kingdon() · test_spawn_all(system_monitor · pyactor_assign · sound)

⑥ Tick loop

UE ticks PyActors → Main.tick(Δt) + pyactor_*.tick(Δt); ue.add_ticker(…) used for async work

⑦ end_play

remove tickers · release_mouse · invalidate world cache · input.shutdown()
